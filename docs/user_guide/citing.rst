How to cite
===========

If you use VANE in academic work, please cite the software release you used. The
repository's ``CITATION.cff`` file holds the citation metadata; GitHub shows it under
**Cite this repository**.

.. code-block:: bibtex

   @software{seo_vane_2026,
     author    = {Seo, Jae Hoon},
     title     = {{VANE}: Visualization and Automated Natural-frequency Extraction},
     version   = {0.1.0},
     year      = {2026},
     url       = {https://github.com/SMI-Lab-Inha/VANE},
     license   = {Apache-2.0}
   }

Please also cite OpenFAST, which produces the linearizations VANE analyses, and the
methods you rely on; the :doc:`../theory/references` page lists them.
